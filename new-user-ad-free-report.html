免廣告不影響核心功能採用 Live 與 Event Play 採用率兩組完全一致；CR Playback Case 略低（−0.7pp），但未達統計顯著（z = −0.95，p ≈ 0.34），屬雜訊範圍，不構成負面訊號。付費頁展示量兩組亦相同，訂閱營收的 +8% 增幅來自相同觸達下更高的付款意願，而非曝光量差異。
補充：Case 轉換數略少，但每次轉換價值更高 全年齡 CVR 觀察顯示 Case 8.55% vs Control 9.17%，但該圖未限定 D0–D7，兩組觀察母體不同，不適合直接比較實驗效果。在相同 D0–D7 範圍內，Case 轉換數略少（819 vs 848），但每次轉換平均營收高出 $1.07（+11.9%）。推測原因：Control 用戶常因廣告插播被推向付費頁、傾向衝動月繳；Case 用戶主動進入付費頁，更傾向選年繳等高承諾方案，少量但高價值的轉換反而帶來更高總營收。

[廣告]

  • 新用戶 D0–D7 僅佔整體廣告母體的少數，免廣告策略對廣告端實際衝擊有限
  • 市場 eCPM 同比大幅走升進一步稀釋絕對損失，廣告端風險在可吸收範圍內

[訂閱]

  • Case 組轉換數略少、但每次轉換價值更高，整體營收淨增 → 免廣告對訂閱的提升並非單純「移除干擾 → 用戶更願意付費」，而是改變了轉換的質量結構
  • Case 組年訂閱佔比明顯提升 → 廣告帶來的訂閱更偏向「衝動式月繳」，Case 組用戶更接近在體驗產品價值時主動進入付費頁，更傾向選擇「高承諾年繳」

[用戶行為] 三項核心功能首次採用率與付費頁展示量兩組無差異，免廣告不改變用戶行為路徑，亦無明顯副作用
